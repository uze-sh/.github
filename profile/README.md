# 🧩 uze

**The package manager and workspace for coding agents.**

<img src="https://raw.githubusercontent.com/uze-sh/.github/main/profile/uze-demo.gif" alt="The uze terminal: several agents at once, each on its own branch in its own checkout" width="860" />

uze gives every coding agent you use the same plugins and the same project
instructions, and lets you run several of them at once without one stepping on
another: a package manager that delivers to Claude Code, Codex, OpenCode and
Antigravity natively, and a workspace that runs each agent in a checkout of its
own.

```sh
curl -fsSL https://uze.sh/i | sh
```
