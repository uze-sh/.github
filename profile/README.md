# 🧩 uze

**Agents come and go. Your work stays.**

<img src="https://raw.githubusercontent.com/uze-sh/.github/main/profile/uze-demo.gif" alt="The uze workspace: several coding agents at once, each on its own branch in its own worktree" width="860" />

A layer between you and your coding agents: the same plugins and one
`AGENTS.md` in Claude Code, Codex, OpenCode and Antigravity, each in its own
format, and a terminal to run them side by side, each agent in a git worktree
of its own. Not an agent itself: no model, no API key.

[Website](https://uze.sh) · [Docs](https://uze.sh/docs) · [X](https://x.com/uze_sh) · [Reddit](https://reddit.com/r/uze_sh)

</div>

### Install

macOS and Linux:

```sh
curl -fsSL https://uze.sh/i | sh
```

Windows:

```powershell
irm https://uze.sh/i | iex
```
